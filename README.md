# Responsive Profile Card

A responsive profile card UI built with HTML & CSS. Features a circular profile image, social media buttons, Subscribe and Message buttons with hover effects, and a stats row with icons.

🔗 **Live Demo:** https://muhammaduzairkhalid15.github.io/Responsive-Profile-Card-Uzi-Solutions/
💻 **Repository:** https://github.com/MuhammadUzairKhalid15/Responsive-Profile-Card-Uzi-Solutions

## ✨ Features

- 🧑 Circular profile image with a colored ring and a header band behind it
- 🔗 Round social buttons for X, GitHub, and LinkedIn with brand colors
- 🔘 Subscribe and Message buttons with smooth hover transitions
- 📊 Stats row (likes, comments, shares) with Boxicons. The numbers are demo values.
- 📱 Card scales down on small screens (`max-width` + `width: 100%`)
- 🎨 Clean rounded card with a soft shadow

## 🔧 Built With

- **HTML5**
- **CSS3** – flexbox, absolute positioning, transitions
- **Boxicons** and **Font Awesome** – icons
- **Google Fonts** – Poppins

## 💡 What I Practiced

- Centering a card with flexbox (`align-items` and `justify-content`)
- Layering a colored header behind the avatar using `::before` and `position: absolute`
- Making a perfectly round image with `border-radius: 50%` and `object-fit: cover`
- Mixing two icon libraries in one project
- Styling button hover states with `transition`
